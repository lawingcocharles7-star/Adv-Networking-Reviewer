# Advanced Networking Reviewer

Open `index.html` in a browser (or host the folder on GitHub Pages).

## Publish with GitHub Pages
1. Create a new GitHub repo, upload everything in this folder (keep `data/` folder).
2. Repo → Settings → Pages → Source: `main` branch, `/ (root)` → Save.
3. Share the link GitHub gives you (`https://<user>.github.io/<repo>/`).

## Add a new lesson
Open `data/lessons.js` or `data/lessons-part2.js` and append a new object at the END of the `LESSONS` array
(same fields as the others: `id`, `title`, `notes`, `cards`, `quiz`). Order = class order.
